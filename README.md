# STARWAKE

**星の彼方へ、撃ち抜け。** スマホ・タブレット・PC向けのオリジナル縦スクロールシューティングです。

## ゲーム内容

- 3宙域の連続キャンペーン。開始宙域は自由に選択できます。
- 5種類の敵、編隊出現、攻撃パターンが3段階に変化する大型ボス3体。
- PULSE（広範囲）、LANCE（前方集中）、SEEKER（追尾）の即時切替。最大レベル4。
- 弾消しと大ダメージのNOVAボム、6秒間のOVERDRIVE。
- 小さな自機判定、かすりによるエネルギー獲得、最大8倍のコンボスコア。
- CADET / PILOT / ACEの3難易度。初めての人にはCADETがおすすめです。
- ステージ別のオリジナルBGM、効果音、爆発、視差背景。
- 難易度・開始宙域ごとのベストスコアを端末内に保存。
- ホーム画面追加・オフライン対応。広告・課金・ログイン・外部素材の読み込みはありません。

## 遊び方

| 操作 | スマホ・タブレット | PC |
| --- | --- | --- |
| 移動 | ゲーム画面をドラッグ | WASD / 矢印キー、またはドラッグ |
| 射撃 | 自動 | 自動 |
| 精密移動 | 指をゆっくり動かす | Shiftを押しながら移動 |
| 武器切替 | PULSE / LANCE / SEEKERボタン | X |
| NOVAボム | NOVAボタン | Space |
| OVERDRIVE | ゲージ100%でボタン | C |
| 一時停止 | 右上のⅡ | Esc / P |

指を置いた瞬間に機体が飛び移ることはありません。指の移動量に追従します。別の指でボム等も押せます。敵弾の当たり判定は機体中心の白い点です。敵機本体への接触には少し大きな判定があります。

レーザーは固定された予告線を1.4秒表示してから発射されます。宙域クリアで耐久とボムが1つ回復します。3番目のボスを倒すとクリアです。ゲーム途中の再開データは保存しません。

## ローカル起動

Node.js 20以上を使用します。依存パッケージのインストールは不要です。

```sh
git clone https://github.com/raitopapa/starwake.git
cd starwake
npm run dev
```

`http://localhost:4173` を開きます。`PORT=8080 npm run dev` でポートを変更できます。同じWi-Fiの端末からはPCのLANアドレスを使って確認できます（通常のLAN HTTPではService Workerによるオフライン保存は有効になりません）。

```sh
npm test
npm run build
```

`dist/` に配信用ファイルと、単独で動く `starwake-standalone.html` を生成します。PCではこのHTMLを直接開いて遊べます。スマホのファイルプレビューアはJavaScriptを実行しない場合があるため、スマホ・iPadにはHTTPSでの公開を推奨します。

## GitHub Pagesで公開

このリポジトリのルートをそのまま配信できます。

1. GitHubの **Settings → Pages** を開く。
2. **Source: Deploy from a branch** を選択。
3. **Branch: main / (root)** を選んでSave。
4. GitHubが表示した公開URLを開く。

すべてのパスは相対指定なので、`/starwake/` のようなサブディレクトリ配信に対応します。GitHub Actionsの「Game checks」はテスト・ビルドと `starwake-web` の成果物保存を行います。公開設定は変更しません。

## オフライン・更新・保存

- HTTPSで初回読み込み後、フッターの **OFFLINE READY** を確認してください。
- iPad / iPhoneはSafariの「共有 → ホーム画面に追加」。Androidはブラウザメニューの「ホーム画面に追加／インストール」を使用します。
- 初回の素材保存が完了すれば、ネット接続なしで本編・BGM・効果音が動きます。
- ブラウザのサイトデータ削除や端末の容量不足で、記録・キャッシュが削除される場合があります。
- コード更新時は `sw.js` のキャッシュバージョンを変更してください。プレイ途中でコードが混在しないよう、新バージョンは開いているゲームのタブをすべて閉じた後に有効になります。
- スコアと設定のみを `localStorage` に保存します。保存できない場合もゲームは遊べますが、記録は次回へ引き継がれません。

## 構成

| ファイル | 役割 |
| --- | --- |
| `src/engine.js` | ブラウザ非依存の戦闘シミュレーション・ステージ進行 |
| `src/render.js` | Canvas 2Dによる機体・敵・背景・演出 |
| `src/input.js` | キーボード・Pointer Eventsによる入力 |
| `src/audio.js` | Web AudioによるBGM・効果音 |
| `src/storage.js` | スコア・設定の保存と検証 |
| `src/main.js` | 画面遷移・HUD・固定刻みのゲームループ |
| `sw.js` | オフラインキャッシュ |
| `tests/` | 戦闘・進行テスト、レスポンシブ確認用ページ |

120Hzの固定刻みでシミュレーションし、描画はrequestAnimationFrameで更新します。画面復帰時の時間飛びを制限し、タブ移動・画面ロック時にはポーズします。敵弾650・自機弾180・パーティクル340を上限にしています。

## 検証状況

自動テストで、全武器の命中、高速移動中の衝突、被弾後の無敵時間、ボム、OVERDRIVE、レーザー予告、スコア保存、3ステージのボス撃破と最終クリアを検証しています。公開用ビルドも確認済みです。

今回の作業環境ではブラウザのURL制限により開発サーバー・ローカルHTMLの実プレイ検証ができませんでした。実機のSafari／Chromeでのタッチ操作、音声再開、画面回転、PWA導入とオフライン再読み込みは未検証です。コード上の対応と実機確認を区別しています。

## アート・音源

機体、敵、惑星、背景、アイコンは本作のために作成したベクター／Canvas描画です。BGM・効果音はWeb Audioで合成するオリジナルです。既存ゲームの画像・音楽・キャラクターは含めていません。外部ランタイムライブラリも使用していません。
