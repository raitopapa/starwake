# STARWAKE ARCADE

**2つの戦場。1つのシグナル。** 縦型と横型を、別々のルール・操作・記録を持つ2本のオリジナルシューティングとして開発しています。

| ゲーム | ZENITH | HORIZON |
| --- | --- | --- |
| 画面 | 縦スクロール / 480×720 | 横スクロール / 960×540 |
| 入口 | `vertical/` | `horizontal/` |
| 軸になる遊び | 弾幕回避、かすり、武器の即時切替 | 地形攻略、カプセルで装備選択、オプション編隊 |
| 主武器 | PULSE / LANCE / SEEKER / WAVE / BURST | PULSE / DOUBLE + 出撃前に選ぶLANCE・WAVE・SEEKER |
| 成長 | Pアイテムで最大LV.4 | SPEED / MISSILE / DOUBLE / BEAM / OPTION / SHIELD |
| BGM | 縦型専用の3曲構成とボス用パターン | 横型専用の3曲構成とボス用パターン |
| 保存 | `starwake.zenith.v2` | `starwake.horizon.v2` |

共通で3ステージ・3ボス・3難易度。NOVAボム、6秒間のOVERDRIVE、最大8倍のコンボ、端末内ベストスコア、ポーズ、オフラインに対応します。画像・音源・フォント・実行コードを外部CDNから読み込みません。広告・課金・ログインはありません。

## 遊び方

| 操作 | PC | タッチ |
| --- | --- | --- |
| 移動 | WASD / 矢印 / ドラッグ | 画面をドラッグ。横型の縦持ち時は画面下のFLIGHT PADも利用可能 |
| 射撃 | 自動 | 自動 |
| 精密移動 | Shift | FOCUSをオン |
| 武器切替 | X | 武器ボタン |
| NOVAボム | Space | NOVA |
| OVERDRIVE | C | ゲージ100%でOVERDRIVE |
| 装備決定（横型） | Z | 装備決定 |
| 一時停止 | Esc / P | Ⅱ |

指を置いただけでは機体は飛び移りません。移動量を追従し、2本目の指でのボム操作もできます。タブ移動・画面ロックで自動ポーズ。ポーズ画面でBGM・効果音の音量と画面揺れ／フラッシュを設定できます。

### ZENITH

- PULSE：広範囲の連射。レベルが上がると弾数が増えます。
- LANCE：直線の貫通レーザー。複数の敵を撃ち抜きます。
- SEEKER：敵を追うミサイル。
- WAVE：左右に揺れる、幅広い貫通波動。
- BURST：5発の近距離散弾。遠方には届きません。

全武器をいつでも切り替え可能。Pで共通レベルが上がります。敵弾をかすめてOVERDRIVEをため、連続撃破でスコアを伸ばします。

### HORIZON

橙色のPカプセルを取るたびに、装備枠が1つ進みます。欲しい枠でZ／装備決定を押すと、その装備を獲得して枠がリセットされます。6枠を超えるとSPEEDへ戻ります。最大になった枠は購入できず、次のカプセルで先へ進めます。

| 枠 | 効果 |
| --- | --- |
| SPEED | 移動速度を最大3段階強化 |
| MISSILE | 地形に沿って進むミサイル。2段階目で天井方向も追加 |
| DOUBLE | 前方と斜め上への射撃を解放 |
| BEAM | 出撃前に選んだLANCE・WAVE・SEEKERを解放 |
| OPTION | 移動軌跡を追う支援機。最大4機。主武器を同時発射 |
| SHIELD | 3回分の防御。使い切る前でも補充可能 |

Shift／FOCUSでは、オプションの位置を固定して低速移動できます。解放した主武器はXで切り替え可能。被弾しても装備を全没収しないため、立て直せます。途中の宙域から開始すると最低限の装備を支給します。

## 当たり判定と見やすさ

- 敵弾に対する自機判定は中心の白い点（半径4px）。翼は判定外です。
- 敵機・地形との接触判定は、横型が半径8px、縦型が半径9pxです。縦型に地形衝突はありません。
- 弾・機体の前フレーム位置を使い、高速移動でも当たり判定をすり抜けないようにしています。
- ボスのレーザーは位置固定の予告を1.4秒表示してから発射。レーザーを横切る移動も検出します。
- 貫通弾は同じ敵に何度もダメージを与えず、1発につき1回です。
- 敵弾は爆発より前面に描画。フラッシュと画面揺れをオフにしても、攻撃予告は残ります。

## 起動・ビルド

Node.js 20以上。通常の開発・テスト・ビルドに依存パッケージのインストールは不要です。

```sh
npm run dev
npm test
npm run build
```

`http://localhost:4173` を開くとゲーム選択画面になります。`PORT=8080 npm run dev` でポート変更、`STARWAKE_ROOT=dist npm run dev` でビルド結果を配信できます。

`dist/` の配信用ファイルに加え、以下の単独HTMLを生成します。

- `starwake-vertical-standalone.html`：ZENITH
- `starwake-horizontal-standalone.html`：HORIZON

PCではHTMLをブラウザで直接開いて遊べます。スマホのファイルプレビューアはJavaScriptを実行しない場合があるため、HTTPSでの公開版を利用してください。

## GitHub Pages

`.github/workflows/pages.yml` が、mainへのpush／手動実行で次を行います。

1. 両ゲームのテスト。
2. 入口・両ゲーム・単独HTMLをビルド。
3. Pages用成果物をアップロード。
4. `github-pages` 環境へデプロイ。

**初回だけ、リポジトリのSettings → Pages → Build and deployment → Sourceを「GitHub Actions」に設定する必要があります。** ワークフローの追加だけでは、この設定を有効化しません。設定後にmainへ反映するか、Actionsの「Publish STARWAKE Arcade」を手動実行してください。

すべてのゲーム内パスは相対指定のため、プロジェクト配信のサブディレクトリにも対応します。公開URLはデプロイ成功後のGitHub Pages画面／Actionsの結果で確認できます。コードの完成と、実際の公開成功は別々に確認します。

## オフライン・更新・記録

- 入口またはゲームで初回の保存が完了し、`OFFLINE READY` が表示されると、両ゲームをオフラインで利用できます。
- 各ゲームのハンガーをホーム画面へ追加すると、そのゲームから起動できます。
- 更新はプレイ中に混ざらない設計です。新しい版を取り込むには、そのサイトのタブ・ホーム画面アプリをすべて閉じて開き直してください。
- 旧縦型v1の設定はZENITHへ引き継ぎます。武器構成が変わったためv2の記録は新規に開始し、旧記録自体は消しません。
- ZENITHは難易度・開始宙域別、HORIZONはさらにビーム別にベストを保存します。ゲーム途中の再開データは保存しません。
- ブラウザの保存制限があってもプレイできますが、記録は次回に残りません。

## 構成と検証

- `index.html` / `portal.js` / `style.css`：ゲーム選択画面。
- `vertical/`・`horizontal/`：それぞれ独立したエンジン、描画、入力、設定、UI。
- `shared/`：音楽合成と矩形の連続衝突判定。
- `sw.js`：2本をまとめるオフラインキャッシュ。
- `tests/`：戦闘、進行、入力、保存、音楽制御、配信資材の回帰テスト。
- `tests/responsive.html`：入口／各ゲームをスマホ・タブレットの寸法で手動確認するページ。

44件の自動テストとビルドを確認済み。両ゲームの実弾による全3ステージ突破、全武器、装備選択、支援機、地形、判定、レーザー予告、音楽の停止・再開、保存の分離を検証しています。通し進行テストは進行確認のため自機を無敵にしており、人間による難易度評価の代わりではありません。

Canvasの描画を画像化し、全6ボス戦を確認しています。任意の再生成ツール `tools/render-previews.mjs` は `@napi-rs/canvas` を使用しますが、ゲーム本体には不要です。

GitHub Actionsでテスト・ビルド・Pages公開が成功し、公開先のChromeで両ゲームの出撃とCanvas描画、横型の撃破・スコア進行・ボム・一時停止を確認しました。実機のタッチ操作、画面回転、Web Audioの出音、PWAインストールとオフライン再読込は未確認です。`tests/responsive.html` と実際のSafari／Chromeでも確認できます。

## 制作物

機体・敵・惑星・地形はオリジナルのCanvas／ベクター描画。BGMと効果音は本作のためのオリジナル合成音源です。グラディウスのようなクラシック作品の横スクロール・装備選択の楽しさを参考にしていますが、既存作品の画像、音楽、名称、キャラクターは使用していません。
